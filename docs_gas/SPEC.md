## 会話で確定した運用方針（要件メモ）

以下は実装・会話で明示されたビジネス判断。再実装時に守ること。

### 顧客・リピーター

- **顧客ID（`09_顧客索引`）は本予約（`03_予約台帳`）のお客さんのみ**が対象。
- リクエスト台帳の人に、リクエスト時点で顧客IDを付けない。
- リクエスト時点でのリピーター自動判定は不要。
- リクエスト詳細の **「この人の履歴」** は、本予約詳細と同様に **顧客検索画面へ遷移**（氏名・メール・電話をプリフィル）。顧客索引は更新しない読み取り専用の照会。

### 同行者フォーム

- 外部受付キーは **URLのみ**（画面にキーは表示しない）。
- ふりがなは **日本語フォームのみ** 表示・必須。
- **送信は1回のみ**（`同行者情報回答済` + シート行でブロック）。
- 下書き: localStorage 自動保存 + サーバー下書き（ScriptProperties）。
- 列ずれ防止: `appendRowBySheetHeaders_`、初期化時 `repairCompanionInfoSheet_()`。

### スタッフWebアプリのセキュリティ

- `/exec` 無効URL・`/dev` 単体アクセス → 案内ページ（管理画面を出さない）。
- スタッフ画面は **`?page=admin` 相当の共有URL**（本番は `?s={token}`）または **`/dev` デプロイ** で開く。
- API は `staffSessionId`（CacheService、12時間、呼び出しごとに延長）で再認可。
- Googleアカウントによる個人認証は行わない（URL秘匿方式）。

### 検索（本予約・リクエスト一覧）

- **1行UI:** キーワード + チェックイン日（日付ピッカー）+ クリア。
- キーワードは名前・ふりがな・メール・電話・IDを **部分一致**（ひらがな/カタカナ正規化、IDは数字の一部でも可）。
- 入力デバウンス約280msで自動絞り込み。

### アーカイブ

- 境界: **チェックアウト日 < 今日**（チェックアウト翌日からアーカイブ）。`archiveCutoffDays` は非推奨。
