## ID体系

| エンティティ | 形式 | 例 |
|--------------|------|-----|
| リクエストID | `STUDIO-RQ{n}` / 初回一括 `MIG-RQ*` | STUDIO-RQ4 |
| 予約ID (STUDIO) | `STUDIO-MT{n}` / `MIG-MT*` | STUDIO-MT149 |
| 予約ID (手動) | `MANUAL-MT{n}` | MANUAL-MT1 |
| 予約ID (過去) | `PAST-YYYY-NNN` | PAST-2026-001 |
| 顧客ID | `CU-YYYY-NNNN` | CU-2026-0001 |
| 外部受付キー | `XXXX-XXXX`（8文字、0/O/1/I除外） | R8K4-XQ29 |
| 部屋割りID | 連番 | （自動採番） |

外部受付キーはリクエスト承認時・本予約作成時に発行。同行者フォームURL・STUDIO連携に使用。

## 02_予約リクエスト台帳

**主要列:** リクエストID, 外部受付キー, ステータス, 姓/名/代表者名, ふりがな, グループ形態, メール, 電話, チェックイン/アウト, 泊数, 宿泊人数, お問い合わせ内容, 連携予約ID, 却下理由, 内部メモ, 返信メール送付済/日時, 作成/更新日時

### リクエストステータス

| 値 | UI表示 | 意味 |
|----|--------|------|
| リクエスト | リクエスト | 新規・承認待ち |
| 承認済 | 承認済 | 承認済（仮予約あり/なし、本予約連携後もこの表示に統一） |
| 却下 | 却下 | 却下 |
| 本予約連携済 | **承認済として表示** | レガシー値。新規書き込みは承認済 |

### 遷移

```
リクエスト ──承認──► 承認済（＋任意で仮予約作成）
           ──却下──► 却下
承認済 ──STUDIO取込/手動紐づけ──► 承認済 + 連携予約ID
承認済/却下 ──差し戻し──► リクエスト（仮予約削除、確定本予約は残す）
```

## 03_予約台帳

**主要列グループ:**

- **管理:** 予約ID, 外部受付キー, 取込元, リクエストID, 予約経路, ステータス
- **代表者:** 姓/名/代表者名/ふりがな, グループ, 連絡先, 住所
- **宿泊:** チェックイン/アウト, 泊数, 宿泊人数（内訳: 大人男女・小学生・幼児等はテキスト保存可）
- **食事・交通:** 食事, BBQ, 交通, 到着時間, 車両
- **アンケート:** 旅行目的, きっかけ, 前回宿泊時期
- **運用:** 割当状況, 同行者情報回答済, メール送付フラグ×3, 支払, 顧客ID, 内部メモ, GCalイベントID

### 予約ステータス

| 値 | 意味 |
|----|------|
| 仮予約 | リクエスト承認で作成。STUDIO取込で上書き確定へ |
| 確定 | 本予約確定 |
| キャンセル | キャンセル |

**アクティブ扱い（IN/OUT/滞在/GCal）:** `仮予約`, `確定`

### 割当状況

| 値 | 意味 |
|----|------|
| 未割当 | 部屋割り行なし |
| 割当済 | 1件以上の部屋割りあり |

### 予約経路（channel）

`自社サイト`, `Airbnb`, `電話`, `その他`, `代入力`（デフォルト: 自社サイト）

---

## 04_部屋割り

部屋割りID, 予約ID, 部屋ID, 部屋名, 利用開始日, 利用終了日, 割当人数, 男女・子ども内訳, 表示用メモ, 部屋割りメモ

- 未割当列の仮想部屋ID: `__unassigned__`
- **表示上の人数は予約台帳を正とする**（予約編集時に部屋割行の内訳も同期）

---

## 05_同行者情報

| 列 | 内容 |
|----|------|
| 外部受付キー | URLキーと一致 |
| 予約ID | 紐づく本予約 |
| 回答日時 | 送信日時 |
| 同行者番号 | 1〜50 |
| 氏名, ふりがな, 年齢, 性別 | ゲスト入力 |

性別選択肢: `男性`, `女性`, `その他`, `回答しない`

---

## 09_顧客索引

顧客ID, 顧客キー, 代表者名, ふりがな, メール, 電話, 来館回数, 最終チェックアウト, 予約ID一覧, 更新日時

**顧客キー:** 正規化氏名 + `|` + （メール or 電話10桁以上）

---

## 12_メールテンプレート

テンプレートID, 名前, 種別（リクエスト/本予約/共通）, デフォルト用途, 件名, 本文, 有効, 表示順

**用途:** 予約確定, 11日前, 3日前 等

**差し込み変数例:** `{{代表者名}}`, `{{チェックイン}}`, `{{同行者フォームURL}}`, `{{本予約URL}}`, `{{却下理由}}`

---

## メール送付フラグ

### リクエスト（02）

- `返信メール送付済` — 承認/却下メール

### 本予約（03）

| フラグ | 種別 | 送付タイミング目安 |
|--------|------|-------------------|
| 予約完了メール送付済 | 予約確定 | 確定後 |
| 11日前メール送付済 | 11日前 | CIの11日前以内 |
| 3日前メール送付済 | 3日前 | CIの3日前以内、同行者2名以上かつ未回答時 |

---

## アーカイブ境界

- **条件:** `チェックアウト日 < 今日`（チェックアウト翌日から移動）
- 03+04 → 07+08、02 → 06
- 移動後も顧客索引は必要に応じて同期
