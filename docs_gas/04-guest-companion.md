# 04. ゲスト向け — 同行者Webフォーム

ファイル: `CompanionForm.html`, `CompanionService.js`  
エントリ: `Code.js` `doGet` → `page=companion`

---

## URL

```
{WebAppBase}/exec?page=companion&key={外部受付キー}
{WebAppBase}/dev?page=companion&key={外部受付キー}   # 開発
```

- キーは **URLパラメータのみ**。画面には表示しない。
- サーバー側で `template.accessKey` をHTMLに注入（クライアントで `?key=` が消える対策）。

外部受付キー形式: `XXXX-XXXX`（英数字大文字8文字、0/O/1/I を避ける）

---

## アクセス検証

API: `companionFormValidateAccess(accessKey)`

| 結果 | 表示 |
|------|------|
| キー不正 | リンクが正しくありません |
| 予約なし | 予約が見つかりません |
| 送信済み | 送信済み（変更はメール案内） |
| OK | フォーム表示 |

送信済み判定:

- `03_予約台帳` の `同行者情報回答済` = TRUE
- または `05_同行者情報` に該当キーの行が存在

---

## 画面フロー

1. **予約サマリー**（読取）— 代表者、日程、人数等
2. **同行者入力** — 1人目から、最大50人
3. **確認** — 送信前ダイアログ
4. **完了** — 変更不可の案内

---

## 入力項目（1人あたり）

| 項目 | 必須 | 備考 |
|------|------|------|
| 氏名 | ○ | |
| ふりがな | ○ | **日本語UIのみ表示・必須** |
| 年齢 | ○ | 0〜120 |
| 性別 | ○ | 男性/女性/その他/回答しない |

### 操作

| ボタン | 動作 |
|--------|------|
| ＋ 同行者を追加 | 最大50人まで |
| 削除 | 確認後に行削除 |
| 下書きを保存 | サーバー（ScriptProperties）+ localStorage |
| 下書きを消す | 確認あり |
| 送信する | **1回のみ**。確認ダイアログ後保存 |

---

## 多言語

UI言語: 日本語 / English / 中文 / 한국어  
※ ふりがな欄は日本語選択時のみ（他言語では非表示）

---

## 保存先（05_同行者情報）

1行1人で追記:

```
外部受付キー | 予約ID | 回答日時 | 同行者番号 | 氏名 | ふりがな | 年齢 | 性別
```

- `appendRowBySheetHeaders_` で列ずれ防止
- 送信成功時: `同行者情報回答済` を予約台帳に TRUE

---

## ゲスト向けAPI（スタッフセッション不要）

| API | 用途 |
|-----|------|
| `companionFormValidateAccess` | 初期検証・サマリー取得 |
| `companionFormSubmit` | 本送信 |
| `companionFormSaveDraft` | 下書き保存 |
| `companionFormClearDraft` | 下書き削除 |

---

## 変更依頼

送信後の変更はフォームから不可。  
`Config.companionFormChangeEmail` に案内メール（未設定時は文言のみ）。

---

## スタッフ側との連携

- 本予約詳細 **同行者情報** ブロックに回答一覧表示
- 2名以上の宿泊で「同行者未回答」TODOにカウント（ダッシュボード・一覧フィルタ）
- 3日前リマインドメールは未回答時のみ pending
